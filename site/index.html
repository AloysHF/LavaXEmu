什么是 LavaX？

LavaX 是早期电子词典与学习机上流行的 LAVA 字节码应用平台。游戏以 .lav 程序分发，运行在设备内置的栈式虚拟机上，使用索引色屏幕与按键/触摸交互。

这些曾经只能在专用硬件上运行的游戏，如今通过 LavaXEmu 在现代设备上重获新生。

核心特性

从字节码虚拟机到虚拟文件系统，全栈 Rust 实现

LAV 字节码虚拟机

117 个操作码的栈式虚拟机，覆盖算术、控制流、内存访问和系统调用，纯 Rust 实现。

系统 API 桥

87 项固件服务分派，覆盖显示、输入、文件、内存、音频与工具函数，完整还原运行时行为。

索引色显示

160×240 分辨率、256 色调色板的帧缓冲管理，还原掌上屏幕的观感。

沙箱虚拟文件系统

受限路径访问与选择性写回，游戏数据文件与存档安全落盘，不会逃出沙箱。

无头确定性模式

无窗口运行 N 帧并截图，配套确定性时钟，方便批量截图与回归测试。

多前端支持

Standalone 桌面端、RetroArch libretro 核心与 EmulatorJS 浏览器核心共享同一套核心逻辑。

快速开始

几行命令，即刻体验

🖥️

Standalone

1

下载最新版本

从 Releases 页面下载对应平台的二进制文件
2

运行游戏

lavaxemu game.lav
3

或使用无头模式截图

lavaxemu --headless --frames 300 game.lav
🎮

RetroArch

1

下载 libretro 核心

从 Releases 页面下载对应平台的核心文件
2

安装核心

重命名为 lavaxemu_libretro 并放入 cores/ 目录
3

加载核心并启动

Load Core → LavaXEmu → Load Content
🔨

从源码编译

1

克隆仓库

git clone https://github.com/AloysHF/LavaXEmu.git
2

编译 Standalone

cargo build -p lavaxemu --release
3

或编译 RetroArch 核心

cargo build -p lavaxemu-libretro --release
