# LavaX 格式与运行时笔记

本文记录 LavaXEmu 已确认的文件格式和运行时互操作信息。

## LAV 文件头

LAV 程序以 16 字节头开始，字节码入口固定为偏移 `0x10`。

| 偏移 | 长度 | 含义 |
|---:|---:|---|
| `0x00` | 4 | 魔数 `4c 41 56 12`（`LAV` + `0x12`） |
| `0x04` | 4 | 编译器/校验相关字段，运行时不直接使用 |
| `0x08` | 1 | 能力标志 |
| `0x09` | 1 | 屏幕宽度除以 16；0 表示使用下限 160 |
| `0x0a` | 1 | 屏幕高度除以 16；0 表示使用下限 80 |
| `0x0b` | 5 | 保留字段 |

能力标志：

- 位 `0`：触摸屏设备；未设置时使用键盘设备；
- 位 `4`：32 位地址空间；
- 位 `7`：24 位地址空间（位 4 优先）；
- 位 `6..5 = 10`：4 位图形；
- 位 `6..5 = 11`：8 位图形；
- 其它值：1 位图形。

宽度限制为 160～320，高度限制为 80～240。已有内容常见 160×80 和 240×160。

## 执行模型

- 来宾值为 32 位小端整数，浮点数使用相同 32 位槽位按 IEEE-754 重解释；
- 运算栈位于来宾 RAM，由一个 8 位栈顶索引管理；
- `0x00..0x7f` 是语言字节码，`0x80..0xff` 是宿主 API 调用；
- 每次宿主帧调用执行一批普通指令；系统 API、输入等待和 delay 会主动让出；
- 16、24、32 位程序使用不同的地址立即数编码，内存本身按字节寻址；
- 图形模式为 1、4、8 位索引色，虚拟机负责调色板和最终 RGB 输出。
